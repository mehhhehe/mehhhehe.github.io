An Image Is Worth 16×16 Words: Transformers for Image Recognition at Scale

authorsAlexey Dosovitskiy, Lucas Beyer, Alexander Kolesnikov, Dirk Weissenborn, Xiaohua Zhai, Thomas Unterthiner, et al. (Google Brain)
venueICLR 2021
paperarXiv:2010.11929 →

As long as I've been studying computer vision, convolutions were the default. The convolution was the load-bearing assumption: locality, weight sharing, translation invariance, all baked into the architecture because images have that structure. This paper asks: what if we don't? What if we hand an image to the same plain transformer that does language, and let scale sort out the rest?

The idea, in one move

Take an image and slice it into a grid of fixed-size patches, 16x16 pixels each. Flatten every patch, project it to a vector, add a position embedding so the model knows where each patch sat, and feed the whole sequence into a standard Transformer encoder exactly as if the patches were word tokens. That's the Vision Transformer. No convolutions, no pooling pyramid, almost none of the hand-built visual machinery. An image treated as a sequence of patch tokens.

A CNN assumes how images work. A transformer asks the data, if you give it enough data to ask.

The catch that makes it interesting

On mid-sized datasets like ImageNet alone, ViT underperforms a comparable ResNet. Convolutions are still useful when data is limited because they encode locality from the start. ViT becomes competitive after pre-training on very large image datasets, where it can learn those relationships from data.

That trade-off is the whole lesson: inductive bias and data are substitutes. A strong architectural prior buys you performance when data is limited; abundant data buys you the freedom to drop the prior and let the model discover the structure itself, often a better-fitting structure than the one you'd have imposed.

What it changed for me

The paper separates architecture from data scale. A model with fewer built-in assumptions can work well, but only when it has enough data. It also made multimodal models easier to reason about, because vision and language could share the same basic Transformer backbone.

What I took away

  • Split an image into patches, embed them as tokens, run a vanilla transformer. No convolutions needed.
  • With limited data, CNNs still win; their built-in priors are a real head start.
  • At very large pre-training scale, ViT matches or beats CNNs with less compute.
  • Inductive bias and data are substitutes: abundant data lets you drop the prior.
